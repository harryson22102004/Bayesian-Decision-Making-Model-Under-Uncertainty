# Bayesian Decision-Making Under Uncertainty
Probabilistic models for optimal decision-making in noisy and unpredictable environments.

### 🔬 Research Highlights
- **Bayesian Inference**: Uses posterior distributions to update beliefs based on incoming environmental data.
- **Utility Maximization**: Implements Expected Utility Theory to choose actions that minimize risk.
- **Machine Learning Focus**: Applies to Reinforcement Learning and Active Learning scenarios.

**Tech Stack:** Python, `PyMC3` / `NumPy`.
